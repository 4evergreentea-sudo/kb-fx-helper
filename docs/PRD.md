# 프로젝트명

외환 창구 업무 도우미

## 1. 프로젝트 배경

은행 외환 창구 직원은 고객을 대상으로 환전, 해외송금 등의 업무를 처리하면서 환율 계산과 거래 내용을 수기 또는 별도 계산기로 처리하는 경우가 많다. 이 과정은 반복적인 계산으로 인한 실수 위험이 있고, 거래 이력을 별도로 정리하지 않으면 이후 확인이 어렵다.

이를 보완하기 위해, 창구 업무 중 환율 계산과 거래 기록 확인을 빠르고 정확하게 도와주는 웹 기반 보조 도구가 필요하다.

## 2. 프로젝트 목표

- 창구 직원이 환전 금액과 환율을 입력하면 정확한 계산 결과를 즉시 확인할 수 있도록 한다.
- 처리한 거래 내역을 기록하고 다시 조회할 수 있도록 한다.
- 별도 서버나 로그인 없이도 브라우저에서 바로 사용할 수 있도록 한다.
- 이후 실시간 환율 연동, 클라우드 저장 등으로 확장 가능한 구조를 마련한다.

## 3. 주요 사용자

- 은행 영업점 외환 창구 담당 직원(텔러)
- 환전 업무를 보조적으로 처리하는 창구 직원

## 4. 필수 기능

- **환전 계산기**: 외화(예: USD, JPY 등) 금액과 환율을 입력받아 원화 환산 금액을 계산한다.
- **거래기록 관리**: 처리한 환전 거래 내역(환종, 금액, 환율, 결과, 처리 시각 등)을 등록하고 목록으로 조회한다.
- **localStorage 저장**: 입력한 거래 기록을 브라우저의 localStorage에 저장하여, 새로고침하거나 브라우저를 다시 열어도 이전 기록이 유지되도록 한다.

## 5. 선택 기능

- **해외송금 계산기**: 해외송금 시 수수료 및 환율을 고려한 예상 송금액 계산 기능
- **실시간 환율**: 한국수출입은행 등 외부 API를 통한 실시간 환율 조회
- **CSV**: 거래 기록을 CSV 파일로 내보내기
- **Supabase**: 거래 기록을 로컬 저장 대신(또는 함께) 클라우드 데이터베이스에 저장
- **Vercel**: Vercel Function을 통한 서버리스 API 프록시 및 배포

## 6. 입력값

- 환전 계산기: 환전할 외화 통화 종류, 외화 금액, 적용 환율
- 거래기록 등록: 거래 일시, 환종, 거래 금액, 적용 환율, 환산된 원화 금액
- 거래기록 검색(선택 기능 확장 시): 조회 기간, 환종 등 검색 조건

## 7. 출력값

- 환전 계산기: 환산된 원화 금액, 적용된 환율 정보
- 거래기록 관리: 저장된 거래 목록(일시, 환종, 금액, 환율, 환산 금액)
- 선택 기능 확장 시: CSV 파일, 실시간 환율 조회 결과

## 8. 예외 처리

- 금액 또는 환율에 숫자가 아닌 값이나 음수를 입력한 경우 계산을 수행하지 않고 안내 메시지를 표시한다.
- 금액 또는 환율이 입력되지 않은 상태에서 계산을 시도한 경우 안내 메시지를 표시한다.
- localStorage 접근이 불가능한 환경(저장 공간 초과, 브라우저 설정 등)에서는 저장 실패를 사용자에게 알리고, 계산 자체는 계속 사용할 수 있도록 한다.
- (선택 기능 확장 시) 실시간 환율 API 호출이 실패한 경우, 마지막으로 저장된 환율 데이터로 대체하고 최신 정보가 아님을 안내한다.

## 9. 완료 조건

- 사용자가 외화 금액과 환율을 입력하면 정확한 원화 환산 금액이 계산되어 화면에 표시된다.
- 계산된 거래를 저장하면 거래기록 목록에 반영되고, localStorage에 저장되어 새로고침 후에도 유지된다.
- 잘못된 입력(음수, 빈 값, 숫자가 아닌 값)에 대해 계산 및 저장이 차단되고 사용자에게 한국어 안내 메시지가 표시된다.
- 위 기능이 데스크톱 및 모바일 화면 크기에서 정상적으로 동작한다.

## 10. 구현하지 않을 범위

- 실제 은행 내부 시스템(코어뱅킹, 원장)과의 연동
- 사용자 로그인/인증, 권한 관리, 다중 사용자 구분
- 실제 자금 이동(송금, 결제, 정산) 처리
- 법적/회계적 효력이 있는 공식 거래 증빙 발행
- 모바일 네이티브 앱 형태의 배포
